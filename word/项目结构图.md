## 🔐 用户认证流程图

### 注册流程

```
┌──────┐                                                    ┌──────────┐
│ 用户 │                                                    │  系统    │
└───┬──┘                                                    └────┬─────┘
    │                                                            │
    │  1. 输入邮箱                                               │
    ├───────────────────────────────────────────────────────────►
    │                                                            │
    │                      2. 生成验证码                         │
    │                         发送邮件                           │
    │◄───────────────────────────────────────────────────────────┤
    │                                                            │
    │  3. 输入用户信息 + 验证码                                  │
    ├───────────────────────────────────────────────────────────►
    │                                                            │
    │                      4. 验证验证码                         │
    │                         检查用户名/邮箱唯一性              │
    │                         密码 BCrypt 加密                   │
    │                         保存到数据库                       │
    │                                                            │
    │  5. 返回注册成功                                           │
    │◄───────────────────────────────────────────────────────────┤
    │                                                            │
```

### 登录流程

```
┌──────┐                                                    ┌──────────┐
│ 用户 │                                                    │  系统    │
└───┬──┘                                                    └────┬─────┘
    │                                                            │
    │  1. 输入用户名 + 密码                                      │
    ├───────────────────────────────────────────────────────────►
    │                                                            │
    │                      2. 查询用户信息                       │
    │                         BCrypt 验证密码                    │
    │                         生成 JWT Token                     │
    │                                                            │
    │  3. 返回 Token                                             │
    │◄───────────────────────────────────────────────────────────┤
    │                                                            │
    │  4. 后续请求携带 Token                                     │
    ├───────────────────────────────────────────────────────────►
    │     Header: Authorization: Bearer <token>                  │
    │                                                            │
    │                      5. 验证 Token                         │
    │                         解析用户信息                       │
    │                         处理业务逻辑                       │
    │                                                            │
    │  6. 返回业务数据                                           │
    │◄───────────────────────────────────────────────────────────┤
    │                                                            │
```

## 🎨 设计模式应用图

```
1. 分层架构模式 (Layered Architecture)
   ┌─────────────┐
   │ Controller  │  表现层
   ├─────────────┤
   │  Service    │  业务层
   ├─────────────┤
   │ Repository  │  持久层
   ├─────────────┤
   │  Database   │  数据层
   └─────────────┘

2. 依赖注入模式 (Dependency Injection)
   @RequiredArgsConstructor
   ├── AuthController ──► AuthService
   ├── AuthService    ──► UserRepository
   └── AuthService    ──► PasswordEncoder

3. 数据传输对象模式 (DTO Pattern)
   LoginRequest    ──► 登录请求
   RegisterRequest ──► 注册请求
   (待实现) LoginResponse, UserResponse

4. 仓储模式 (Repository Pattern)
   UserRepository extends JpaRepository
   └── 封装数据访问逻辑

5. 工具类模式 (Utility Pattern)
   JwtUtil        ──► JWT 令牌工具
   CaptchaCache   ──► 验证码缓存工具

6. 异常处理模式 (Exception Handling)
   @RestControllerAdvice
   └── GlobalExceptionHandler
       └── 统一异常响应
```
